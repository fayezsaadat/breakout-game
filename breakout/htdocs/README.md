# آجرشکن — Breakout

یک بازی کامل ۲بعدی با **HTML5 Canvas خالص** — بدون هیچ کتابخانه یا فایل خارجی.
تمام گرافیک، صدا (سنتز WebAudio) و فونت روی بوم رسم می‌شود.

## اجرا

```bash
cd breakout
python3 -m http.server 8080 --bind 0.0.0.0
# سپس مرورگر را روی http://localhost:8080 باز کنید
```

هر سرور استاتیک دیگری هم جواب می‌دهد (فایل‌ها ES Module هستند و از طریق HTTP سرو می‌شوند).

**نسخهٔ تک‌فایل:** `breakout.html` همان بازی کامل است در یک فایل — بدون شبکه،
قابل اجرا حتی با دابل‌کلیک از روی دیسک. بازسازی آن:

```bash
node tools/build-single.js
```

## امکانات

- **۲۰ مرحلهٔ دست‌ساز** + قفل/بازشدن پیشرفت + رکورد هر مرحله (localStorage)
- **ویرایشگر مرحله**: نقاشی با ماوس، کد متنی برای اشتراک‌گذاری، آزمایش و ذخیرهٔ مرحلهٔ دلخواه
- **فیزیک پیوسته (swept collision)** — توپ حتی در سرعت‌های بالا از آجر رد نمی‌شود
- **۵ نوع آجر**: عادی، مقاوم (۲ ضربه)، سنگین (۳ ضربه)، فولاد (فقط لیزر)، منفجرهٔ زنجیره‌ای
- **۱۰ پاور‌آپ**: راکت پهن/باریک، چندتوپ، لیزر، آهسته/سریع، چسبنده، سپر، جان اضافه، زمان کند
- **سیستم کمبو** با ضریب امتیاز تا ×۸
- **ذرات، تکه‌شیشه، حلقهٔ انفجار، متن شناور، لرزش صفحه**
- **صدا و موسیقی رویه‌ای** با WebAudio (بدون فایل صوتی) + تنظیم بلندی و بی‌صدا
- کنترل با **ماوس/لمس و کیبورد** هم‌زمان، مکث، تمام‌صفحه
- رابط کاملاً فارسی (RTL) روی بوم + چیدمان واکنش‌گرا (letterbox)
- **پشتیبانی گوشی/آیپد**: بازی همیشه **افقی و تمام‌صفحه** — با اولین لمس تلاش برای
  fullscreen + قفل جهت landscape؛ در پلتفرم‌هایی که اجازه نمی‌دهند (iOS) رندر به‌صورت
  خودکار ۹۰ درجه می‌چرخد («landscape مصنوعی»). کنترل لمسی (کشیدن = راکت، ضربه = پرتاب)،
  دکمهٔ مکث لمسی، و بزرگ‌شدن خودکار متن‌ها و دکمه‌ها در صفحهٔ کوچک

## کنترل‌ها

| ورودی | عملکرد |
|---|---|
| ماوس / لمس | حرکت راکت |
| ← → یا A D | حرکت راکت با کیبورد |
| Space / کلیک | پرتاب توپ، شلیک لیزر |
| Esc / P | مکث |
| R | شروع دوبارهٔ مرحله |
| M | بی‌صدا |
| F | تمام‌صفحه |
| ۱–۶ (در ویرایشگر) | انتخاب قلم |

## معماری

```
js/
├─ main.js            راه‌اندازی
├─ core/
│  ├─ math.js         RNG قطعی، AABB، برخورد پیوستهٔ دایره/مستطیل
│  ├─ emitter.js      EventBus سبک برای جداسازی سیستم‌ها
│  ├─ input.js        لایهٔ action-based ورودی + bindDefaultActions
│  ├─ render.js       viewport با DPI و letterbox، لرزش دوربین، کمکی‌های رسم
│  ├─ audio.js        سنتز SFX + سکانسر موسیقی ۱۶-گامی
│  ├─ storage.js      ذخیرهٔ namespaced در localStorage
│  ├─ ui.js           ویجت‌های immediate-mode روی بوم (دکمه، اسلایدر، …)
│  └─ game.js         پوستهٔ برنامه: حلقهٔ rAF، صحنه‌ها، رویدادهای سراسری
├─ game/
│  ├─ brick.js paddle.js ball.js powerups.js particles.js levels.js
└─ scenes/
   ├─ menu.js game.js editor.js
```

## تست

```bash
node tools/test.mjs    # 68 تست واحد روی همان کلاس‌هایی که مرورگر اجرا می‌کند
node tools/smoke.mjs   # بوتِ پوستهٔ کامل + ربات که هر ۲۰ مرحله را بازی می‌کند
node /home/user/.e2e/check.mjs    # e2e با Chromium واقعی + اسکرین‌شات هر صحنه
node /home/user/.e2e/buttons.mjs  # کلیک واقعی روی همهٔ دکمه‌ها در ۳ اندازهٔ پنجره
node /home/user/.e2e/mobile.mjs   # شبیه‌سازی آیفون: لمس، کشیدن، دکمهٔ مکث لمسی
```

اسکرین‌شات‌های تأیید بصری در `tools/shots/` هستند.
